# Poppins

Unmodified Poppins 4.004 TrueType fonts, weights 400, 500, 600 and 700, copied from
the project's approved local UI reference. Embedded name tables identify Poppins
and the copyright notice below; these four assets are distributed under the SIL
Open Font License 1.1 in [OFL.txt](OFL.txt).

Copyright 2020 The Poppins Project Authors (https://github.com/itfoundry/Poppins).

License verified on 2026-09-15 against the [Google Fonts Poppins license](https://github.com/google/fonts/blob/main/ofl/poppins/OFL.txt).
No external font requests are made at build time or in the browser. The application
uses the original family name Poppins; the mockup's internal font alias is not a
separate font family or a modified font asset.
